# قصه‌خانه — پروژه خام اندروید

این پروژه یک نمونه اولیه بومی اندروید با Kotlin و Jetpack Compose است.

## امکانات فعلی
- ذخیره محلی داستان‌ها و دسته‌بندی‌ها روی همان گوشی
- چند دسته‌بندی اولیه و دو داستان نمونه (یکی رایگان و یکی قفل‌شده)
- جست‌وجو در عنوان، متن و دسته‌بندی
- افزودن، ویرایش و حذف داستان از پنل مدیریت داخل برنامه
- ورود مدیریت با رمز پیش‌فرض `1234` (حتماً در تنظیمات عوض شود)
- قفل آزمایشی داستان و بازکردن محلی برای تست رابط کاربری
- علاقه‌مندی‌ها، حالت شب، تغییر رنگ اصلی، نام نمایشی و شعار برنامه
- تنظیم اندازه متن هنگام مطالعه

## محدودیت‌های مهم این نسخه
- قفل آزمایشی **پرداخت واقعی نیست**؛ کاربر می‌تواند آن را از داخل برنامه باز کند. قبل از انتشار تجاری باید پرداخت درون‌برنامه‌ای کافه‌بازار و اعتبارسنجی سمت سرور/سازوکار امن خرید پیاده‌سازی شود.
- اطلاعات فقط روی گوشی ذخیره می‌شود. پاک‌کردن داده یا حذف برنامه ممکن است اطلاعات را از بین ببرد.
- نامی که در تنظیمات تغییر می‌کند نام نمایشی داخل برنامه است؛ نام زیر آیکون لانچر برای تغییر به تنظیمات بسته و ساخت APK جدید نیاز دارد.
- تغییرات فعلی در حافظه داخلی برنامه ذخیره می‌شوند؛ هنوز خروجی/ورودی پشتیبان‌گیری اضافه نشده است.
- این نسخه فعلاً جلد تصویری، بارگذاری فونت دلخواه و پنل مدیریت وب ندارد.

## ساخت APK
1. Android Studio را نصب کن.
2. از صفحه Welcome گزینه **Open** را بزن و پوشه `GhesseKhane` را انتخاب کن.
3. صبر کن Gradle Sync تمام شود.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیر.
5. برای نصب آزمایشی، APK ساخته‌شده را به گوشی منتقل و نصب کن.

حداقل SDK: 23 (Android 6.0). برای ساخت به اینترنت و Android SDK/Gradle نیاز است.
